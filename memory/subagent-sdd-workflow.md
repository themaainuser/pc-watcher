- 2026-10-24: Reviewer prompts earn their cost — they caught real bugs no implementer self-review found: cross-thread `UnhookWinEvent` is a no-op per MSDN (T10), ferrisetw callbacks panicking → `process::exit(1)` (T11), and a tray-Exit shutdown hang proven with a standalone repro (T13). - 2026-10-24: Pre-declare implementer deviations in the report and paste them into the reviewer prompt for explicit verdicting — turns deviations into reviewed decisions instead of surprises.
- 2026-10-24: Keep a cross-task flag ledger (this repo: `.superpowers/sdd/<slug>/ledger.md`, flags F1–F15). Every review finding that constrains a LATER task becomes a dated flag line folded into the next task's brief/dispatch; prevents boundary regressions across 15 tasks.
- 2026-10-24: OWNER-MANUAL rule held all project long: elevated smokes (`schtasks`, `--install`, ETW capture example, hibernate/video-call volume tests) are never run by agents; agents may only compile-check them. README must never contain fabricated measurements.
- 2026-10-24: Test-count pinning trick reviewers accept: when a fix needs coverage but the plan pins the workspace test total, fold new assertions into an existing test (F7 config fix did this) — acceptable only when coverage genuinely increases, and state it in the report.
- 2026-10-24: Whole-branch final review structure that worked on a 15-task branch: dispatch spec-compliance and quality reviewers IN PARALLEL (independent), then a second-opinion reviewer that challenges BOTH reports claim-by-claim, re-runs gates, and consolidates into ONE priority-ordered fix list with explicit "cut these" and "must NOT change" lists — followed by a single consolidated fix round + scoped re-review ("APPROVED — branch shippable"). The second opinion genuinely re-graded severities (MAJOR→MODERATE) and cut 4 items; don't skip it.
- 2026-10-24: Save reviewer reports to DISK files before dispatching a reviewer expected to read them — a completed subagent's output exists only in the caller's context; when a reviewer only speaks its report, write it to .superpowers/sdd/<slug>/final-*-review.md yourself so the next dispatch can pass a path.
- 2026-10-24: Mutation-proven regression tests are review currency: implementers/reviewers prove a guard test bites by temporarily reverting the fix and capturing the concrete failure (e.g. `left: 0, right: 5`), then restoring. Use for any test guarding a subtle invariant (counter lifetime, shutdown-once); reviewers accept it as verification evidence.
- 2026-10-24: After a fix subagent dies mid-edit, first run the gates YOURSELF, then inventory exact compiler errors (`cargo check --all-targets` error list with file:line) into the repair dispatch prompt — a precise error inventory (delimiter cut-off, duplicated test fns, stale helper signatures) made the repair a single cheap dispatch instead of a redo.
